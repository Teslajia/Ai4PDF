# Ai4PDF 完整使用指南

左侧 PDF 原文 / 逐段双语对照 / 纯译文，右侧自定义 AI。文件、批注、译文、对话和阅读页码保存在本机。无需注册账号，不依赖远程 CDN。

## 安装版（推荐）

Windows 10 / 11（x64）下载 Release 中的 `Ai4PDF-1.1.0-windows-x64-setup.exe`，双击安装后从桌面启动。无需 Python 或 Node.js，自动打开浏览器，托盘菜单可打开界面或退出服务。安装向导可选择本地文档库位置，默认 `%LOCALAPPDATA%\Ai4PDF\data`，支持选择已有 Ai4PDF 文档库；升级、卸载保留个人数据。

另提供解压即用的便携 ZIP。安装、旧文档迁移、源码构建和 GitHub 发布流程见 [RELEASE.md](../RELEASE.md)。项目以 [AGPL-3.0](../LICENSE) 开源。

## 源码版启动

Windows 双击 **start.cmd**。浏览器打开 http://127.0.0.1:8765/ 。保持服务窗口运行，关闭窗口或按 Ctrl+C 停止服务。已安装的本机环境可以直接使用。

换电脑时需要 Python 3.11+、Node.js 22+，先执行 `setup.ps1` 安装依赖。也可手动执行：

```powershell
cd Ai4PDF
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
.\.venv\Scripts\python.exe app.py --open
```

端口被占用时可用 `python app.py --port 8766 --open`。服务仅监听 `127.0.0.1`。

## 使用

右上角总设置提供「系统语言」：默认简体中文，可切换繁體中文、한국어、日本語、English，立即生效并自动保存在当前浏览器，无需配置 API。界面菜单、提示、设置和手动切分工具随语言切换；文档原文、已有译文、批注笔记、对话、模型 ID 与自定义名称保持原样。AI 新回答默认使用所选系统语言，明确提出其他语言要求时遵从提问。双语对照的目标语言独立设置，支持简体中文、繁體中文、한국어、日本語及 English，选择会单独记住；切换系统语言不会改变翻译目标，也不会清空各语言的译文缓存。

1. **打开 PDF**：点击按钮或拖入文件（100 MB 以内）。相同文件自动恢复已有记录。左边的「文档」可打开历史文件；「目录」支持 PDF 书签；「搜索」按原文文字查找页码。
2. **配置 AI**：右上角设置中填写 API 地址、实际模型 ID 和 API Key。「显示名称」可自由命名，例如「ChatGPT 官方」，用于右侧连接标识；实际调用仍使用「实际模型 ID」，切换模型不会改变自定义名称。旧配置自动兼容，未填写显示名称时继续显示模型 ID。输入框下方「图片」右侧的小设置按钮可快捷调整模型与思考强度，支持输入任意模型 ID 或选择本浏览器最近使用的模型。点击保存后用于后续问答和翻译，当前请求不变；关闭面板不保存草稿。思考强度默认为「跟随模型默认」，不额外发送参数；选择其他档位后发送标准 `reasoning_effort`，可选 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`，具体支持范围取决于模型和服务商（[OpenAI 官方参数说明](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)）。不支持时可恢复默认，不会自动重试或更改你的选择。支持 OpenAI **Chat Completions** 兼容服务，包括 DeepSeek、兼容中转、Ollama / LM Studio 等。基础地址自动补 `/v1/chat/completions`；以 `/v1` 结尾则补 `/chat/completions`；完整 `/chat/completions` 地址原样使用。非标准路径请填写完整地址。
   两个设置入口的模型字段右侧都有「获取模型」按钮：填写 API 地址和 Key 后点击，通过同一连接的 `GET /models` 获取服务商返回的模型 ID（[官方接口说明](https://developers.openai.com/api/reference/resources/models/methods/list)），无需先填写模型 ID。展开选择器时显示完整列表，可搜索或直接点选，不会按当前模型名称过滤掉其他选项。获取列表不会发起模型生成；模型是否支持当前 Chat Completions 请求仍取决于服务商。列表仅缓存在当前页面内存，按 API 地址和 Key 隔离，两个入口共享；刷新页面后可重新获取。API 不提供列表时显示原因，仍可手动填写。选择后点击保存才用于后续请求。
3. **验证连接**：设置中的「测试连接」会真实调用一次填写的模型，可能产生少量 API 费用。不使用 API Key 的本地服务可留空。原生 Anthropic Messages / Responses API 协议未实现，需要兼容网关。
4. **提问与图片附件**：右侧输入问题，Enter 发送，Shift+Enter 换行；支持流式输出、停止和 Markdown。AI 回复中的 LaTeX 行内公式（`\(...\)`、`$...$`）及独立公式（`\[...\]`、`$$...$$`）会自动渲染，历史对话重新打开后同样生效；代码块保留原文，超宽独立公式可横向滚动。点击输入框下的「图片」、在输入框粘贴截图，或把图片拖到右侧助手即可添加附件。支持 PNG / JPEG / WebP，每条消息最多 4 张、单张 10 MB、2500 万像素；WebP 在本机转换为 PNG。发送前可点击预览或移除，也可只发图片。图片随当前文档的对话保存在本机，重新打开后可查看，最近 12 条消息中的图片会一并作为后续问答上下文；总图片大小超过 40 MB 时提示新建对话。发送失败后可「重新编辑问题」恢复文字和图片。需配置支持图片输入的模型和 Chat Completions 兼容 API；纯文字模型不会自动获得识图能力。点击回答中的 `p.3` 等引用可定位原页。选中原文后点「问 AI」，会附带选中文字。
5. **批注**：在 PDF 或双语「原版图文」的原文中拖选文字，选择高亮、下划线或带备注的高亮。译文也支持同样的操作（一次选一段内的文字，支持跨行）。支持四种颜色；「批注」侧栏可编辑备注、定位、删除。单击已有高亮、下划线或备注标记，会显示批注预览和「编辑」按钮，可直接修改对应批注；原文 PDF、双语图文原文及译文均支持。同一位置的多条批注会分别列出，拖选文字仍用于创建新批注。批注编辑窗口不遮暗或模糊文章，可拖动标题栏移动；聚焦标题栏后也可用方向键微调。位置在当前页面内记住，窗口缩小后自动保持在可见范围内。批注自动保存。右上角「导出批注」下载含标准 PDF 原文高亮/下划线和备注的副本，可在其他支持批注的阅读器里查看或编辑。译文批注按目标语言、段落和文字选区保存，随双语 Markdown 导出，不写到原 PDF。重译后文字变化时，旧批注保留在侧栏并标明「译文已更新」，不会错误套用到新译文。
6. **全文 / 指定页翻译**：切到「双语对照」，选目标语言，在「翻译范围」填写起始页和结束页，再点击翻译按钮。包含起止页，页码按 PDF 实际页序计算。默认选择全文，也可点「选择全文」恢复。只翻译范围内未完成的段落，进度对应所选范围；每份文档的范围会在当前浏览器记住。逐段原文 / 译文交替显示；可随时暂停（当前段完成后生效）、继续、重译单段；失败后保留完成部分。译文缓存按文档和目标语言区分。右上角下载按钮导出整份文档的双语 Markdown。 每段译文在「重新翻译」左侧提供「折叠 / 展开」，仅收起当前译文，原文继续显示。折叠状态按文档、目标语言和段落保存在当前浏览器，刷新及切换显示方式后保留。展开时恢复公式与批注；从批注侧栏跳转到折叠的译文时会自动展开。
7. **原版图文 / 纯文字**：双语对照默认使用「原版图文」。原文内容直接从 PDF 页面渲染，保留字体、图片、矢量图表、表格、行内及独立公式；在段落或连续图文块之后插入译文。检测到双栏时保留栏结构，手机上将栏依次排列。自动略去页首、页末的大块空白。原文图像按页加载并缓存在本机，上方叠加 PDF.js 文字层，可直接选字、复制、划线及批注；每个文字片段只出现一次，避免复制出整页重复内容。译文是可选中的网页文字，批注随窗口宽度和换行重新定位。译文中的 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式由本地 KaTeX 排版；复制单段译文时跳过隐藏的公式辅助文字。「纯文字」模式也支持译文批注，原文批注需切回「原版图文」或 PDF。
8. **公式和图内文字免翻译**：根据文字字体、坐标及图形区域识别独立公式、公式编号、图片与图表内的文字，保留原 PDF 画面，不把这些片段送给模型，也不插入碎片译文栏。正文及图注正常翻译；正文中的行内数学符号要求模型保留。范围进度只统计可翻译段落；仅有公式、图内文字的页面不调用 API。已有文档自动应用筛选，旧碎片译文保存在缓存中但不再显示或计入进度；其批注仍可在侧栏查看。若正文段落原先混入独立公式，保留原始段落 ID，仅用清理后的正文重新翻译；界面会提示需要更新该段，其他正文译文继续复用。
9. **页眉页脚免翻译**：结合跨页重复、页边位置、字号及与正文的间隔，识别含作者名、论文简称和页码的页眉，以及重复页脚。支持奇偶页交替的页眉和变化的页码；首页标题、正文小标题及正文中的同名词语仍正常翻译。原版画面保留页眉页脚，其旧译文自动隐藏，也不计入进度或发送给模型。升级自动重建筛选缓存，无需重新导入 PDF；原有译文和批注文件不删除。
10. **手动切分与合并**：在双语「原版图文」每页标题右侧点击「调整切分」。选择「横向切分」或「纵向切分」后，在目标块的行间或栏间空白处点击；也可先选中块，输入块内百分比后「按位置切分」。选择「多选合并」，连续点选相邻块，再点「合并所选」；选中的区域必须能组成矩形。「全选」后合并可从整页重新划分栏和段落。支持撤销、重做、恢复自动结果；点击「保存调整」才生效，取消不保存。选中单块可以修正待翻译文字，或勾选「此块不翻译」排除公式和图片。切分边界不能穿过文字行，靠近文字时会尝试吸附到空白。完整且未改动的段落继续使用已有译文，重新分组或修改文字的段落需重新翻译；旧译文及批注不删除，历史译文批注仍可从侧栏查看并随 Markdown 导出。调整按文档、页码保存在本机，刷新后生效；恢复自动切分可恢复对应原段落的译文。该功能调整双语阅读排版，不拆分或合并磁盘上的 PDF 文件。

## 纯译文、引用与阅读位置（v1.1）

- 在「双语对照」右侧点击「纯译文」，阅读已有译文以及识别到的原图、表格和独立公式；可继续按页码范围翻译、折叠或重译段落。切换视图不额外调用 API。
- 图表与对应的图注、表注译文按阅读顺序排列，图内文字保持原样。小图不会拉满整栏，长图等比适应窗口；点击「放大查看」打开预览。有文字层的图表可以选字、复制和批注，标记与原文视图共享。加载失败时可重试。
- 图形识别遵守 PDF 的裁剪范围，避免把隐藏路径所在的正文误当图片；重新打开旧文档会自动刷新识别缓存，保留已有译文、批注及手动记录。复杂布局仍可用手动切分修正。
- 点击原文或译文中的编号式引用可跳转到参考文献，多篇引用会提供选择菜单；PDF 原生内部链接优先。底部「返回阅读位置」可回到跳转前的位置。没有可识别目标时不会猜测跳转位置。
- 原文、双语、纯译文切换时定位相应段落或图表；缩放、刷新及重新打开文档时恢复原文的阅读位置。浏览器存储不可用时无法持久保存这些界面位置。
- 在纯译文视图点击导出可获得仅译文 Markdown；双语视图导出原文和译文。Markdown 暂不嵌入图表，也不生成重新排版的译文 PDF。

## 文档库管理与迁移

- 左侧「文档」→「管理文档库」，或总设置中的「本地文档库」→「管理文档库」，可打开管理面板。旧文档自动归入「未分类」，无需重新导入。
- 支持创建、重命名和删除文件夹，以及按文件夹、标签筛选；支持搜索标题、文件名、标签和按标题排序。文件夹是单层逻辑分类，不改变原始 PDF 的磁盘路径。删除文件夹只将其中的文档移至「未分类」。
- 点击文档旁的「编辑」可修改显示标题、文件夹及标签。标签用逗号分隔，每份文档最多 30 个标签，每个标签最多 40 个字符。勾选文档或「全选当前列表」后，可批量移动、添加/移除标签、删除和恢复；切换筛选条件会清空选择，避免操作隐藏的文档。
- 「删除」先移入回收站，保留 PDF、批注、译文、对话、图片和手动切分记录。可单份或批量恢复；在回收站选择「彻底删除」并确认后才移除磁盘文件。重新导入内容完全相同的 PDF，会恢复回收站里的原记录。正在阅读的文档被删除时，阅读区回到首页。
- 设置显示实际文档库位置和文档数量。展开「迁移文档库位置」，填写一个**空目录或尚不存在的目录的绝对路径**，点击「迁移并切换」。无需先配置 AI 或保存 API 设置。迁移会复制整个资料库（含回收站），逐文件进行 SHA-256 校验，然后切换；迁移期间请保持本地服务运行。应用的写入会等待复制完成，再写入新位置。
- 迁移完成后立即生效：安装版的位置记录在 `%LOCALAPPDATA%\Ai4PDF\library-location.json`，源码版记录在项目目录的 `library-location.json`，重启后继续使用新位置。原目录保留为备份，不再接收新记录，也不会自动删除。迁移失败时仍使用原目录；目标目录可能保留部分副本，检查后选择空目录重试。已迁移的磁盘不可用时，启动会报错而不会悄悄创建空库。
- 若用 `AI4PDF_DATA`（或旧版 `PAPERDESK_DATA`）环境变量指定目录，环境变量优先，界面显示该位置并禁用迁移；需修改环境变量并重启。普通启动可直接在界面迁移。

## 数据与边界

- 默认库：安装版为 `%LOCALAPPDATA%\Ai4PDF\data`，源码版为项目目录的 `data/`，迁移后以设置中显示的位置为准。库根目录的 `library.json` 保存文件夹、标签、修改后的标题和回收站状态；`<文件哈希>/original.pdf` 是原文副本；`document.json` 是文字和目录；`state.json` 是批注、译文、对话及页码；`attachments/` 是聊天图片和图片元数据。停止服务后备份整个当前库目录，即可保留所有文档及分类记录。清除浏览器存储不会删除这些文件。新对话清空对话记录，但不自动清理已保存的附件文件。浏览器保存 API 配置、界面偏好和上次打开的文档 ID。
- `layout.json`、`translation-policy.json` 和 `previews/` 是可重建的本地布局、翻译筛选与页面预览缓存。图文模式沿用已有段落 ID，不清空或重新分配已保存的译文。双栏公式按栏识别和合并，忽略图形的纯白底板；单双栏切换的分界避开两侧完整段落与公式，防止译文插入正文或公式中间。图文原文与 PDF 视图共用同一组批注；文字层按可见页面加载，不需要将整篇 PDF 逆向转换为 LaTeX。翻译筛选使用本地启发式规则，特殊字体或复杂排版仍可能存在识别误差。
- `manual-layout.json` 保存各页手动分块、文字修正和翻译段落的对应关系，属于需要备份的用户数据，不是自动布局缓存。新段落使用独立 ID，防止旧译文或批注被错误套用。手动调整只改变翻译使用的段落，全文搜索与 AI 文献上下文仍使用 PDF 原始提取结果。页面坐标不变，原文划线及 PDF 批注导出照常工作。
- API Key 默认只保存在当前页面内存，刷新后需重填。明确勾选「记住 API Key」才写入浏览器 localStorage；不写入服务器文件。共享电脑上请不要勾选。
- AI 请求由本地服务转发，因此不受浏览器跨域限制。只有触发问答、测试、翻译或获取模型列表时才连接填写的 API。获取模型列表仅请求模型信息，不发送文档或对话。问答发送论文文字/片段、选区、最近对话及其中的图片附件；翻译逐段发送原文。选择图片时仅在浏览器预览，点击发送后保存至本机并发送到配置的模型服务。PDF 文件本身不上传第三方。模型服务商的日志和保留政策由其负责。
- 长文问答超过约 55,000 字符时采用关键词片段选择，界面会显示「部分相关段落」。它不是向量检索，中文提问对英文长论文的召回可能有限；选中相关段落提问更准确。可按服务的上下文容量调整 `app.py` 中 `context_for` 的预算。
- 扫描 PDF 暂无 OCR；图文模式可显示页面，但翻译/文字选择需要先使用外部 OCR。加密文件需先解锁。复杂表格、公式、旋转文字或异常双栏排版的文字提取可能不完整；图文模式保留其原版画面。布局分段是基于坐标的启发式分析，重叠图文可能合并展示。插入译文会拉长页面，不承诺译文后的分页与原 PDF 相同。
- 原文公式不经 OCR 重建，因此能保持原貌；译文公式的正确性仍取决于模型是否返回了正确的 LaTeX，工具不会自动猜补提取时丢失的符号。现有双语 Markdown 导出仍为文字和公式源码，不包含页面图像。
- 翻译按 PDF 文字块和行距识别段落，超长段落会拆分，跨页段落可能分成两段。不会把整个原版 PDF 覆盖为译文；双语结果可导出 Markdown。
- 当前支持导出批注后的 PDF，**不自动覆盖磁盘上的原 PDF**。已存在的外部批注保留在导出文件中；在 Ai4PDF 内新增的批注可在侧栏编辑，原 PDF 已有的批注暂不导入编辑列表。
- 同一份文档建议仅在一个标签页编辑；批注使用逐条保存，聊天与阅读位置由最近写入的标签页决定。

## 实现与验证

Flask + PyMuPDF + PDF.js + KaTeX，前端为原生 ES Modules。所有前端依赖由本地 `node_modules` 提供，入口 `static/index.html`，核心逻辑 `static/app.js`、`app.py`、`layout.py` 和 `translation_policy.py`。安装版使用 Waitress 和系统托盘启动器，经 PyInstaller / Inno Setup 打包。项目按 AGPL-3.0 开源，第三方组件保留各自许可；发布产物包含对应源码和第三方声明。
